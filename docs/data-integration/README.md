## 计数与映射含义

按当前app.json注册路由列出页面；按读写、身份、上传、分页筛选、表单字段与交互列需求。需求可以共享接口，一项需求也可能依赖多个接口，因此需求数不等于接口数。不使用旧63页面状态数代替实际盘点。

后端以函数及read/write子操作分别计数，另列身份通道、HTTP及内部函数。代码匹配按read/write函数和op、action/runtime函数对应；通用写重试/分页需求对应现有共享入口，签名PUT对应mediaUpload产生的能力。6项部分匹配通过明确需求ID关联现有可参考接口，但不表示需求已经实现；匹配不表示必填参数、返回字段、权限、状态或上线条件完全满足。Gap包含具体契约/接入问题、配置依赖与未确认能力，不能全部称缺接口。

Gap关键字用于网页辅助关联，完整记录为独立问题清单；泛化或跨业务事项需在同事讨论中确定影响范围。未找到明确匹配的需求也留在对照中，不静默丢弃。本地存储/微信原生能力单独列出，不误判为缺后端。
