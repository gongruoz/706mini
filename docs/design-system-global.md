## 唯一主题与实现入口

- `components/ui-icon-button/`：隔离样式的正圆图标按钮；当前全局返回入口使用。可见宽高同源，点击区独立，图标来自 illustrations。
- `miniprogram/lib/theme.js`：所有路由、浮层、导航和日历导出共用令牌；旧 `paper/community` 参数兼容但不切换主题。
- `styles/editorial.wxss`：全局基础、详情、列表、表单与状态；移除由社区组件接管的旧活动卡、动态及轮播规则。
- `styles/community.wxss`：全局共享邀请卡与首页编排。所有页面拥有相同样式根类；不再由是否有插画决定主题。
- `templates/screen.wxml`、`templates/sheets.wxml`：共享结构和操作；`lib/illustrations.js` 为全局图标映射。
- `scripts/build-community-icons.cjs`：32 单位画板、2 单位圆头描线，导出 96px 本地 PNG；不依赖系统 emoji。

## 稳定规则

画布 `#F5F5F2`，内容白色，主文字 `#232323`，辅助文字 `#6B6B66`，主要操作黄 `#FFE568`。注记、候补、审核、回复使用中性色，危险与错误保留功能红。原始头像和媒体保持彩色。

文字按角色选择：40 主标题、34 活动标题、32 区块、28 正文/人名、24 事实/说明、22 时间/辅助、20 只读标签；正文 400、人名/栏目 600、活动标题 700，强调操作可用 500。正文行高 1.7，标题 1.3–1.4。 native 菜单对齐控件可有有界的光学校准，不按路由另设字号体系。

页边 32rpx；内部 8/16，标题间隔 24，卡片间 32，模块 56/72，动态间 88。内容卡默认无描边/阴影；输入保留细灰边。最新方向取消主操作、导航选中项、搜索键等装饰描边，按语义逐类迁入组件（导航与搜索已落地，普通按钮仍待迁移）。毛玻璃只用于导航／悬浮操作外壳及媒体上的返回控件，不扩展到正文或 carousel。

内容角 32rpx，活动外角 44、海报 38、窄白边 6；输入 24，弹层上角 48；按钮/导航最大胶囊，头像正圆。原生图像裁切窗口为宽高 3:4，不拉伸原图。

## 组件和流程

- 公开活动列表、日历、空间、成员历史、个人活动和报名列表复用 `eventCard`。个人状态和管理操作留在卡片外，不混成活动自身状态。草稿点击仍进入有权限的活动预览。
- 发布第三步复用只读邀请卡；只组装标题、时间、地点、费用、容量和封面等公开字段，不复制群二维码/微信号到预览对象。
- 设置同组菜单为完整白色块；消息保持列表，待处理内容为白色面，普通通知不加活动卡式边框。已读仍保留可读主文字。
- 浏览路由保留共享导航。发布、专题创建/编辑、资料/空间编辑、创建空间、引导、登录、反馈和审核详情属于任务路由，隐藏 tab。任务表单与审核动作固定在独立底部栏，预留安全区；键盘显示时操作栏退出悬浮，避免与输入重叠。
- 每个决策区域只有一个主要操作；小辅助按钮为白色，取消为轻文字。审核、报名、支付状态的真实文案与下一步不变；待审核不冒充成功报名。
- 提交中沿用按钮 loading/disabled，防重复提交；用户不能在提交中关闭弹层。内部成功跳转可正常关闭弹层。
- 错误不清空表单/弹层输入；弹层错误不再重复出现在底层。字段错误靠近字段，普通错误说明可重试。刷新保留内容，以轻量状态提示等待；初载使用标题、文本和卡片骨架。
- 关闭已修改但尚未发送的弹层，先询问继续编辑或放弃；成功提交后的内部关闭不重复询问。任务页沿用已有自动草稿，不清空现存内容。
- 微信支付、授权、相册、图片预览、系统确认继续使用原生能力，不自行仿制支付或权限面板。

### 顶部通栏与底部导航复用

活动详情/预览有图时内容从屏幕 y=0 开始，图片延伸至状态栏背后，不再占用 headerHeight 的画布空白；去掉活动导航标题，返回控件浮在图片上。无图/加载中仍为控件留出可读的正文起点。所有子页面共享 subpage-navigation 透明背景，取消原先不透明的整块标题安全区，表单正文保留必要的控件避让。
