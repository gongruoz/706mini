# 706：关注与发现的设计试行

2026-10-23：用户已确认将试行方向推广全局。当前规范与验收边界见 [全局社区设计系统](design-system-global.md)；下文保留两页设计演变记录，不再代表仅首页生效。

2026-10-23，基于 `befa772`。内容样式范围为原生「关注」「发现」；共享导航现已延伸到全部路由，其余内容沿用 Paper。真实服务配置、业务数据与权限规则保留，网页原型 `dist/` 不作为本轮验收结果。

## 出发点：在共同规则中保留各自的表达

本轮对参考图的解释是设计者自己的工作判断，并非对原作者意图的考证：严谨的网格、清楚的文字和少量几何形状，为多样的照片、海报和人的表达提供公共秩序。趣味来自规则中的变化。

706 是公共生活的载体。界面应让人先看见谁在邀请、发生什么、是否可以参加；品牌则通过贯穿全页的比例、字重与形状留下记忆。白色承载内容，少量黄色强调操作；照片和海报保持原色，不把界面收色误解为抹平发起者自己的表达。

## 具体决策与理由

最新一轮依据用户确认的收敛方向，将人物、活动、日历和轮播容器改为白色。界面装饰只保留黑、白、黄与中性灰，媒体不置灰；只有导航使用半透明毛玻璃，carousel 明确不使用。边界由字号、内边距和区块间距共同建立，细黑线用于关注按钮等局部操作，不回到满页线框。

| 决策空间 | 本轮选择 | 理由 |
| --- | --- | --- |
| 人物推荐横向或纵向生长 | 紧凑横向，头像旁固定文字区，姓名与关注分置左右 | 浏览的是人与自己的关系，避免把每个人做成竖向商品陈列 |
| 推荐原因附属在哪里 | 融入白色人物卡上缘的灰黑单行旁注 | 不再以紫色增加一层视觉竞争，关系仍与人物成为同一整体 |
| 关注按钮的视觉与操作大小 | 可见胶囊 100 × 56rpx，透明按钮仍至少 44 × 44px，置于文字区右侧 | 可见高度约为头像的 2/3，让黄色回到辅助操作的位置；点击范围不随视觉一起缩小 |
| 所有组件同一圆角或区分 | 操作胶囊，人物/轮播/日历 32rpx，活动外角 44rpx、海报内角 38rpx | 内外圆角差等于 6rpx 白边，形成包裹关系而非重复描边 |
| 如何建立边界 | 去掉描边、分隔线和头像轮廓，依靠色面与空间 | 完整体块比线框更直接；秩序来自对齐、字重和间距 |
| 海报是附图还是主体 | 右侧固定宽高 3:4，自身圆角，外留 6rpx 窄白边 | 保持海报主体感，同时让图片清楚地嵌入同一白色邀请 |
| 海报与长内容冲突 | 原图不拉伸，文本允许卡片自然增高 | 固定比例不能以隐藏关键事实为代价 |
| 轮播满图压字或分区 | 左侧约 2/3 文案、右侧约 1/3 照片/几何图形 | 标题拥有稳定、清楚的阅读区，图片保留自己的表达 |
| 多彩铺满还是局部强调 | 中性底、白色表面、黑字，黄色集中到操作与选中态 | 去掉整块淡紫/淡绿/浅黄容器；媒体保留原色与个人表达 |
| 全部玻璃或选择性材质 | 仅保留既有导航玻璃，其余内容为清楚的实色白底；轮播不加玻璃 | 统一来自比例与秩序，不依赖每个容器拥有相同透明度 |
| 字体统一粗体还是有主次 | 活动/栏目标题较强，人名突出，动作描述较轻 | 先识别人和活动，再读辅助事实 |
| 导航四个气泡或一个索引 | 浅色半透明完整胶囊、四等分布局，黄底细黑线选中项 | 保留完整轮廓的稳定感，减少页脚重量；各页不再切换两套导航 |
| 图标细描线或几何体块 | 四枚均为空心圆润线稿：爱心、笑脸、信封、人物，统一 2 单位描线 | 参考清晰、可爱、简明的图形语言；可爱来自弧线和比例，不用实心剪影破坏轻重一致性 |

用户给的海报参考用于指导右侧 3:4 图片、独立圆角与极窄内嵌边。活动文字处于清楚的白色区域，没有仿制模糊背景。发布加号按用户最新确认恢复为右下方、导航上方的原位悬浮按钮；移除顶部发布入口，恢复搜索框原有宽度。

## 真实内容与图形的边界

- 真实模式下保留服务端返回的空间与专题照片，放入右侧图像区；无图时提供几何封面。
- 离线演示的轮播使用本地几何构图，替代种子中的渐变占位封面，不写回种子数据，也不宣称是空间实景。
- 几何语汇只用圆、拱形、条带与方块，关联共享空间里的桌面、开口与相聚。使用两种固定构图，不为每张卡片新增装饰语言。
- 活动海报保留原图，按 3:4 视窗裁切，可点击查看完整原图。无海报仍明确占位，不伪造活动照片。
- 标题、状态与人数、日期时间、地点、发起方、费用都保留；未知容量不填造分母。不恢复推荐星星、个人报名长条与封面时间胶囊。
- 头像和姓名继续进入成员页；关注操作独立；节点轮播直接进入对应空间页。

## 图标

矢量源：`scripts/build-community-icons.cjs`；映射：`miniprogram/lib/illustrations.js`。以 32 单位画板、2 单位描线、圆形端点与圆角连接导出 96 × 96 透明 PNG，资源随包加载。

四导航采用空心爱心、圆脸笑脸、圆角信封、圆肩人物；统一墨色与线宽，移除关注的实心人物，发现由指南针替换为用户指定的笑脸，逐枚校准轮廓尺度。日历、地点、发起方、搜索与发布也使用同样的圆头线稿。所有操作保留文字或无障碍名称。全部路由及保留的 custom-tab-bar 组件使用同一资源和导航样式，不再切换 emoji 或反白版本。选中状态的边框空间始终保留，不增加切换时的形变或滑动动画。

半透明背景始终保留；支持 `backdrop-filter` 的渲染器再叠加模糊，不以玻璃效果支持情况影响导航可读性。底部保留安全区与内容滚动余量，不修改原有路由、筛选或弹层逻辑。

### 导航与白色内容的边界

- 整个胶囊外缘增加 1rpx、16% 墨色的浅灰细线；外部叠加 4.5% 的柔和阴影与 1.8% 的近缘阴影。保持半透明底和毛玻璃，不改变卡片底色或选中项的墨色边框。
- 内边距从 6rpx 调为 5rpx，由新增的 1rpx 边框补齐，外部高度、内部图标及选中项位置保持不变；全部路由共用。

### 动态文字系统收敛

- 推荐与报名汇总使用同一「姓名 / 动作 / 时间 / 正文」结构，不再因动态类型切换排版。汇总中的真实人名同样强调，人数和报名动作保持辅助层级，不把整行都加粗。
- 延续 Paper 的系统字体、28rpx 正文和语义字号令牌；移除试行版报名正文单独缩为 25rpx 灰字的例外。原 Paper 层的同类历史规则由最后导入的统一正文样式覆盖，其余路由不扩改。
- 不更换视觉方向：白卡、窄边内嵌 3:4 彩色海报、黄色操作、胶囊导航与圆头线稿保留。后续按信息角色复用规则，不为单条内容添加特例。
