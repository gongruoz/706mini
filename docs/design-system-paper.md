# 706 Paper：当前设计与交互规范

2026-10-17 更新。本文是原生小程序当前规范，取代此前试验中的旧尺寸与行为说明。当前采用「轻编辑式」：安静的版面中放少量精致贴纸；外部舒展，内部精密；活泼来自人、海报和关系，不是每个控件争取注意力。改版前的本地 Git 检查点为 `5d875ed`。

## 实现入口

- 语义颜色、尺寸参数：`miniprogram/lib/theme.js`。
- 当前样式：`miniprogram/styles/editorial.wxss`，在 `app.wxss` 末尾导入；旧结构样式不是另一套有效规范。
- 共享页面与活动卡片：`miniprogram/templates/screen.wxml`。
- 展示规则、状态、页面动作：`miniprogram/lib/page.js`。
- 底部胶囊导航：`miniprogram/custom-tab-bar/`。
- 图标映射 / 顶部原生安全区：`lib/icons.js` / `lib/navigation-layout.js`。
- 表单步骤与校验 / 海报布局：`lib/forms.js` / `lib/calendar-poster.js`。

## 1. 视觉基础

| 项目 | 当前规范 |
| --- | --- |
| 画布 / 表面 | 暖白 `#FAF9F5` / 纸白 `#FFFDF8` |
| 主文字 / 次要文字 | 炭黑 `#282822` / `#706F65` |
| 主要高亮 | 淡黄 `#FFF5A3`，轻底 `#FFFBE3`；用于主要行动、选择和日历入口 |
| 辅助色 | 淡紫用于推荐原因、关系解释与回复便笺；淡绿用于可参与/完成状态；警示使用红色文字和必要细线，不用颜色代替状态说明 |
| 边线 | 统一 1px；黄色操作、独立活动邀请与人物贴纸保留墨色收口；投稿外层取消边框，状态和关系便签通常不描边；灰线只用于必要分隔与输入边界 |
| 间距 | 基础 8rpx；页边 32rpx；区块间 56rpx；标题到内容 32rpx；列表卡片间 32rpx |
| 常规字号 | 页标题 40rpx，区块标题 30rpx，正文 28rpx，辅助 22–24rpx；紧凑标签约 18–20rpx |
| 组件 | 内容卡片常规圆角 32rpx；活动卡片 44rpx；胶囊只包裹必要内容；常规主要操作至少 88rpx 高 |
| 表面与动效 | 无常规阴影、无 tab 跳动/旋转/位移动效；图片保留真实色彩 |

颜色必须有语义：黄色是品牌与操作的主角，不把所有卡片涂黄。紫色不是第二个按钮色，绿色不代表“可点击”。正文不为追求紧凑而省略必要日期、地点或状态；长内容应自然换行。

## 2. 全局导航与安全区

- 四个主 tab 不显示“706”“消息”“我的”等重复页眉，不显示调试横幅。城市与发现搜索控件按微信菜单胶囊真实位置对齐，不用固定猜测顶部尺寸。
- 顶部背景覆盖系统状态栏与真实菜单所在区域，只有下缘约 48rpx 柔和消失；不能让正文从关闭按钮后透出来。空标题页面仍保留保护层。
- 底部浮层在上缘约 36rpx 渐变，操作区域为稳定的暖白底，控制文字不与下面内容重叠；外围透明区不拦截内容点击。
- 四入口：🪁 关注 / Following、🪩 发现 / Discover、📮 消息 / Messages、🪴 我的 / Me。外胶囊纸白，当前项淡黄内胶囊；单项高 132rpx、emoji 50rpx、标签 24rpx。
- 主页面预留 248rpx 加系统底部安全区；发起按钮 80rpx，使用 ➕，避让导航；弹层打开时隐藏 tab，关闭恢复。
- 城市胶囊无下拉 emoji；搜索按钮收在搜索框内。返回/层级提示使用克制的普通 ‹ / ›，不是反复出现的箭头 emoji。
- 消息的全部/管理/活动/互动置于同一顶部安全行，与原生微信菜单胶囊中心线对齐；右侧预留菜单区，英文内容可横滑，不压缩字体。
- 开发者入口只在演示、develop 或 trial 环境出现；真实 release 不展示。开发者入口承接身份切换、演示模式和页面目录，不改变正式用户权限。

## 3. 推荐成员与关注流

### 节点橱窗

节点指具体空间/社区据点，不混入个人、组织、专题或城市目录卡。顶部单个手动 carousel 直接出现，不另加“城市里的相聚之处 / 我关注的节点”标题行；每张都是一个具体空间，点击整张卡直接进入对应空间主页，不经过节点列表。已关注节点同城在前、异地保留城市，去重后最多展示 4 张；暂无关注时可展示最多 2 张同城探索，明确标注来源，绝不标成已关注；不自动关注。完整节点目录仍可从其他明确的目录入口进入，不占用 carousel 卡片。

节点和发现专题直接复用 screen.wxml 的 featureCarousel 模板：统一 280rpx 高、同一圆角容器裁切、全幅图片/遮罩、淡黄小标签、标题和说明。整张卡片可点击，不另显示“走进空间 / 查看系列”文字入口。圆点使用同一白色选中态、半透明未选中态，位于图片内部；每张 slide 完整填满容器，无额外底部空带或卡片级边框，前后边距为 0，多卡循环衔接。不自动播放、不显示数字与左右按钮。节点卡固定携带 `space` 路由和该空间 ID；不能放入跳向列表的城市总览卡。目录复用 spaces 路由，支持当前城市/我关注的两个视角；登录者的关注跨页读取，游客可浏览城市，关注目录须登录。某个来源失败时保留动态与可读节点，并可重试；不伪造热度或更新。

### 人物贴纸

- 横向胶囊 368 × 160rpx，头像 112rpx，左右内边距 24rpx，头像与文字间距 16rpx。
- 推荐原因是无描边的上缘淡紫便签，不另放装饰气泡。推荐列表排除当前本人。
- 文字区是明确的隐形框：姓名左对齐、关注控件右对齐；长名省略，不挤压按钮，不把按钮贴到外层弧线上。
- 简介最多两行。头像/姓名进入成员主页；关注操作独立处理。已关注显示“已关注 / Following”，点击再提供取消关注选项，而不是持续暴露否定操作。
- 小胶囊保持视觉紧凑，必要时通过透明触控区扩大点击范围。已关注为安静文字，不再画一层灰色胶囊。“换几个”不附装饰 emoji。

### 动态投稿

投稿外层无边框、无底板、无额外圆角，和页面共用暖白画布；投稿末尾留 64rpx。作者头像 72rpx，头像与姓名进入主页。正文前后 20/24rpx，内嵌活动保留主要轮廓与纸白表面。聚合报名解释比真实投稿更安静，不显示“合并动态”等内部机制。第一屏应能见到真实动态，不让两个横滑推荐区占满两屏。

## 4. 统一活动卡片

- 左文字、右海报；内边距 28rpx，图文间距 24rpx，右图 216 × 216rpx、圆角 36rpx，纵向居中。头像和活动图片有 1px 深色细线。
- 列表海报为方形裁切窗口，不拉伸；点击图片可独立预览原图。图片失败时显示明确占位，而不是破图或留空。后端继续返回原始媒体，不输出页面专属裁切文件。
- 标题 29rpx、行高 1.4、最多两行；信息 22rpx、行高 1.55。日期使用自然中文/英文，跨日补结束日期，非当年补年份。
- 标题下只显示一个无描边的只读状态/人数标签，例如“报名中 12/20”。容量未知时显示参与人数，不能编造分母；候补、已满、结束、取消分别有文字。
- 人数不是隐蔽管理按钮，不因用户角色跳向不同页面。点击卡片进入详情，管理入口只在详情按权限出现。
- 发起者和组织合并为一行，个人发起不重复“个人发起”；地点独立一行。费用在左下。
- 不展示当前个人的报名状态、参与者头像长条、封面时间胶囊或推荐星星；不在卡片中显示发起者头像，详情保留。
- 所有使用共享活动卡片的页面遵循同一信息契约；“我的报名”列表可在卡片外展示必要的个人报名进度与下一步。

## 5. 发现与日历

### 发现

- 专题 carousel 位于顶部搜索下方；日历入口紧接在 carousel 下方，仅显示“活动日历”，小字“本周 x 个空间 · y 场活动”。这是当前城市未筛选的本周总览，不随下方的下周/免费/名额等条件变化。
- 专题以图像与标题表达内容，横向滑动切换；保留低调圆点位置提示，不显示“1/2”或左右切换按钮。
- 筛选保留三行但不显示“时间/地点/参与”列名，全部左对齐：本周/下周；全部空间/具体空间；免费/有名额。后两项可叠加；有条件时出现重置，不以 emoji 补回被删除列名。
- 删除筛选中的活动日历、共读、放映、户外；日历拥有独立入口，不与普通筛选混淆。服务端保留旧 tag 能力，界面不暴露分类快捷项。
- 结果标题使用“x 场活动”，英文按单复数处理；零结果明确显示，不以旧数量替代 0。

### 活动日历与海报

- 本周/本月与正式日期范围；日期格、星期与计数预留统一高度，空日期也占位。
- 周与月都显示该周期的对应列表；默认完整周期，不自动选中首个有活动日。点击某日筛选列表，再点取消选日；月视图不因此跳成周视图。
- 页面采用一条纵向内容流，不嵌套可滚动时间轴；日期概览与活动列表职责分开。
- 生成海报先预览，再保存图片。海报左侧日期/时间线、中间活动信息、右侧原比例海报；长标题换行、活动较多时增加画布高度，不静默删除活动。
- 海报右上使用服务端签发的小程序码；演示环境明确标识无有效码，不伪造二维码。中文/英文系统文案跟随语言；用户内容不自动翻译。
- 真实扫码、相册授权和多机型超长海报仍需真机联调。

## 6. 活动详情、评论与审核

- 详情首屏封面高 320rpx；时间、地点、名额等决策信息优先于参与者汇总与专题关联。
- 发起方仍显示真实头像与权限关系。自定义地点不伪装成可进入的空间页；详情保留完整介绍。
- 分享、再次发起及撤回推荐为“大家说”前的轻量文字操作；底部推荐为次操作，主要操作由状态决定：报名、查看参与方式、付款保留名额、报名审核进度或候补进度。已满无候补不能继续报名。
- 评论采用细线头像、紧凑写评论胶囊与淡紫回复便笺；删除/取消等操作保持确认与权限校验。
- 审核详情先说明当前身份、审核范围和状态引导；展示图文、关联活动、必要审核方与已有意见；关联活动逐个按现有读取权限获取，失败明确提示，不能借审核接口越权拉取。
- 审核进度给出当前下一步；草稿/退回可进入修改再提交。通过、退回操作防重复点击，退回理由仍必须填写。

## 7. 消息与我的

- 消息移除“全部标为已读”；保留分类、未读提示和单条已读逻辑。
- 待处理消息归入“需要关注”，使用卡片与明确动作；普通消息作为更安静的列表。已读在字重/色彩上减弱，但内容仍可读。前端分组不改变服务端消息生命周期。
- “我的”按我的参与 / 我的发起 / 我的管理 / 偏好与设置分组；空管理分组不显示。城市、语言直接可达，更多承接其他偏好。
- 成员主页无重复的顶部“更多操作”和“编辑资料”；自己的资料卡内保留编辑入口。资料、作品、常出没于和历史活动保持区块留白。

### 空间主页

顺序为身份/简介/地址/开放信息 → 公开负责人和公众号 → 最多两篇回顾预览（可展开更多）→ 最多三场近期活动 → 空间成员。近期活动只含未结束的公开活动，全部活动入口保留过往记录。成员模块从活动上方移到下方；已有数据只证明公开参与，不声称是“活跃”，因此标题为“空间成员”。

负责人由空间显式发布的公共链接提供，再经过 member 公开资料接口读取；不可读取或资料私密时跳过，不从管理员角色推断，不显示私人微信。公众号和文章直接由点击触发微信原生打开；不支持/失败时显示明确说明和用户主动复制入口，不静默复制。演示文章标识为虚构预览、不调用外部账号。

本轮使用 entity.public_links 的 host/official_account/recap 类型表达资料。所有空间明确显示“认识这个空间”和“空间回顾”分区；缺资料时显示只读的待补充说明，不把整个结构隐藏，也不填造负责人、账号或文章。706 青年空间、Sola 共创空间、杭州 706 客厅提供明确虚构的演示资料；既有 public_links 数组（含空数组）不覆盖。真实数据、写入白名单及公众号主体关联仍需后端/运营联调，不能将演示预览当作已接通真实公众号。

## 8. 表单与状态

- 新人三步：打个招呼 → 找到同好 → 准备出发。昵称/城市和 2–5 个兴趣为必要信息，头像/简介可稍后；私密微信号、作品与社交链接放编辑资料，不强迫新人一次填完。
- 活动三步：介绍活动 → 安排参与 → 预览提交。专题三步：介绍专题 → 关联活动 → 预览提交。每步有名称和简短引导，预览不泄露参与群二维码/联系方式。
- 向前一步先校验当前必需项，提交校验全部；错误在字段附近，自动定位对应步骤；服务端错误仍保留表单，不清空输入。
- 活动检查未来开始时间、结束晚于开始、自定义地点/地址、正整数容量或不限、正价格、至少一种参与方式；专题至少一个关联活动。客户端校验不替代服务端规则。
- 草稿与步骤按账号/模式/路由保存。新人“稍后继续”只存本机；正式提交仍需隐私确认。保存/提交期间按钮防重复点击。
- 加载用安静的骨架，错误可重试且已有内容不被清空；空列表、媒体失败、权限变化和失效状态须明确表达。

## 9. 图标与双语

Emoji 只用于可识别的功能：日期 🗓️、地点 📍、组织 🎪、发起 ➕ 等；相同语义复用映射。不要把 emoji 当作通用点击暗示。人物、海报、小程序码和微信原生控件不替换为 emoji。装饰不重复读屏，纯图标控件保留功能标签。

系统文案跟随中英文偏好，活动标题/用户简介/组织名保持原文。不能用机器翻译覆盖用户内容；英文换行、长名称和较大字号需要实际核对，不假定中文通过就等于双语验收。
